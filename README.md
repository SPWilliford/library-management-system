# library-management-system

A library management system including catalog search, borrower records, checkouts and returns, and fine
tracking. JavaFX desktop client over a Spring Data JPA layer and a MySQL database.

Built for CS 4347 (Database Systems) at UT Dallas, fall 2023. Assigned as a group project.

Java 17, Spring Boot 3.1, Spring Data JPA, JavaFX 21, MySQL, Maven. Schema and seed data in
`docs/`.
